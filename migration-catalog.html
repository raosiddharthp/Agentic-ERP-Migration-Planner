Migration Catalog – Common Patterns, Risks & Phases

This catalog provides the foundational knowledge base used by the Agentic ERP Migration Planner. It includes common migration approaches, typical phases, known risk categories, and industry benchmarks. All data is static and open for enterprise customization.

Common Migration Approaches

Approach Description Typical Duration Risk Level Best For
Big Bang Single cutover event — old system off, new system on 6–12 months High Smaller organizations, greenfield implementations
Phased (by module/geography) Roll out modules or business units sequentially 12–24 months Medium Most common enterprise approach
Hybrid / Parallel Run New system runs alongside old for validation period 18–36 months Low–Medium High-risk industries (finance, healthcare)
Technical Upgrade Only Same vendor, version upgrade (e.g., ECC → S/4HANA technical) 9–18 months Medium Minimal process change needed

Standard Migration Phases

Phase Key Activities Typical Duration
Discover & Assess Current state analysis, fit-gap, business case 2–4 months
Design & Blueprint To-be processes, data migration strategy, customizations 3–6 months
Build & Configure System setup, development, integrations 6–12 months
Test & Validate Unit, integration, UAT, performance testing 4–8 months
Cutover & Deploy Data migration, go-live, hypercare 1–3 months
Optimize & Stabilize Post-go-live enhancements, knowledge transfer Ongoing

Common Risk Categories & Examples

Category Examples Severity Triggers
Data Migration Data volume > 1TB, legacy custom tables, poor data quality High if historical data > 10 years
Custom Code > 5,000 custom objects, heavy Z-code, deprecated APIs High if > 20% of functionality custom
Integrations > 50 third-party interfaces, real-time sync required High if mission-critical (banking, payroll)
Business Process Change Standardization across geographies, new operating model High if multiple legacy instances
Organizational Readiness Limited internal expertise, resistance to change High if no prior cloud experience
Compliance & Regulatory SOX, GDPR, industry-specific (e.g., GxP, HIPAA) High in regulated industries
